# Northwind Traders - Executive Sales Performance Dashboard

## 📊 Project Overview
This project transforms raw sales data from the classic Northwind Traders dataset into a modern, interactive executive dashboard using Power BI. 

## 🛠️ Technical Implementation
- **Data Modeling:** Built a robust Star Schema with complex table relationships.
- **Relationship Management:** Configured bidirectional cross-filtering to ensure seamless interactivity across multiple data tables.
- **DAX Measures:** Developed custom measures for Revenue ($797.08K) and Total Units Sold (32K).
- **UI/UX Design:** Implemented a high-contrast corporate theme with a 6-panel grid layout for optimal readability.

## 📈 Key Insights
- **Top Markets:** The USA and Germany represent the strongest revenue streams.
- **Product Performance:** Successfully identified high-volume inventory items vs. high-value revenue drivers.
- **Daily Trends:** Mapped sales fluctuations to identify peak operational windows.
